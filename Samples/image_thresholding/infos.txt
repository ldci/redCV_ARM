It’s been a month now that I’ve been extensively testing the ARM-64 version of Red for macOS.  Thanks to Xie Qingtian for spending a lot of time making this version available.  Thanks also to Red/Sensei for all our discussions and his constant help. A few observations. The interpreted version of Red is very fast. I’ve noticed a difference of about one second compared to compiled code that calls routines using Red/System code. Well, we have to struggle with the new pointers like `ptr-value!` or `ptr-ptr!`. The compiler is unforgiving: even the slightest error in the code is penalized. For example, a routine that calls another routine within its function body causes a crash at runtime.
I've just spent some time adapting the redCV code for the ARM-64 processor, and I hope to make it available to everyone in the near future.
