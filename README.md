
# Computer Vision with Red Language on ARM-64
### see [http://www.red-lang.org](http://www.red-lang.org) 

![](images/red.ico) ![](images/redCV.png)
### You need an ARM-64 Red version.
Thanks to Xie Qingtian for spending a lot of time making this version available. Thanks also to Red/Sensei for his constant help. 

### Created and tested with Tahoe 26.6.2 version of macOS on Apple's M1/M2 processor

Code is functional with Red 0.6.6. for macOS ARM. 


A few libraries and examples are still missing. They'll be added ASAP.

You must compile examples since red routines are required.
Use -t Darwin-ARM64 or -t macOS-ARM64 compiler options.
In case of problems add -u compiler option. See [https://www.red-lang.org](https://www.red-lang.org) for details.
### Documentation
The code is roughly similar to that of the 32-bit version, with the exception of pointer handling.  So use the [https://github.com/ldci/redCV/tree/master/docs](https://github.com/ldci/redCV/tree/master/docs) for documentation.

**Extra documentation here :** [http://redlcv.blogspot.com/2017/04/blog-post.html](http://redlcv.blogspot.com/2017/04/blog-post.html)
